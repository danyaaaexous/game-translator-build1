# Rune Atelier

A warm, premium single-page rune-to-English translator.

## Add the final rune artwork

Place transparent PNG files in `public/runes/` using the names `rune_a.png`, `rune_b.png`, and so on through `rune_z.png`. Numeric files use `rune_0.png` through `rune_9.png`. Each image is automatically paired with its matching English letter or number. Built-in glyphs remain visible as fallbacks until the final artwork is supplied.

## Local preview

Run `npm install`, then `npm run dev`.
