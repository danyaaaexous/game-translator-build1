# Rune artwork

Place transparent PNG files here as `rune_a.png`, `rune_b.png`, and so on through `rune_z.png`.

Numeric rune files use `rune_0.png`, `rune_1.png`, and so on through `rune_9.png`.

The interface automatically uses each image for its matching English letter. Until an image is added, a built-in runic glyph is shown as a fallback.
